# Software-development-best-practices

Conjunto reaproveitável para quem quer começar e manter projetos com boas práticas. Nada aqui altera configurações globais: você copia o que quiser, quando quiser.

- `CLAUDE.md`: regras curtas que valem sempre. Copie para a raiz de um projeto, ou acrescente ao `~/.claude/CLAUDE.md` para valer em todos (se esse arquivo já existe, acrescente; não sobrescreva).
- `skills/boas-praticas/`: a skill `/boas-praticas`, com o checklist completo.
  - `/boas-praticas auditar` confere um projeto existente e entrega um relatório.
  - `/boas-praticas iniciar` guia um projeto novo, etapa por etapa.

## Instalar a skill

Só neste projeto: copie `skills/boas-praticas` para `.claude/skills/boas-praticas` dentro dele.
Em todos os projetos: copie para `~/.claude/skills/boas-praticas`.
